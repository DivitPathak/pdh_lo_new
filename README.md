# Clearsign Plain Language Guide

AI helper that explains rent, loan and insurance documents in simple English or Hindi. Upload a photo or PDF, get red/amber/green warnings and what to ask before you sign. Personal data is masked and nothing is stored.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://clearsign-plain-language-guide.lovable.app
